# 🧠 decisions.md

## 🎯 目的

設計・仕様・実装に関する意思決定と、その理由を記録する。

---

## 📌 使い方

- 「なぜそうしたか」を必ず残す
- 後から見て判断理由が分かる状態にする
- 却下案も含めて記録する

## 📝 運用ルール

- Decisionは必ずID（D-XXX）で管理する
- 小さな判断でも記録してよい
- 後から変更された場合は履歴を残す
- 過去のDecisionは削除しない

---

## 🔄 更新フロー

```text
1. 判断が必要になる
2. 選択肢を整理
3. 決定

```
