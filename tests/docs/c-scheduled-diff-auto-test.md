# C 定時差分検知テスト（popup）

## 目的

本番 C の baseline・通常監視・ダウンロード・Chrome 通知・外部拡張通知を変更せず、URL 差分の `newUrls` 検知を確認する。

このテストは、初回取得のURLから1件を除外した一時baselineを作り、同じページを再取得して除外したURLを新規URLとして検知する。実際の商品変化を待たずに差分経路を確認できる。

## 手順

1. 拡張をリロードし、popup の `テスト` → `B/C: 定時監視` を開く。
2. 有効な C サイトを選び、`差分検知テスト` を押す。
3. 結果カードで「URL取得」「テスト用baseline作成」「再取得」「newUrls検知」「テスト終了」が成功することを確認する。
4. C の通常監視を開始していないこと、ダウンロード・Chrome 通知・外部拡張通知が発生していないことを確認する。

初回の商品一覧描画は最大30秒待機する。30秒を超えても準備できない場合は、`DOM準備待機が完了しませんでした` と表示して終了する。

## Gmail も確認する場合

1. popup の Gmail 通知を有効化し、宛先を設定して `テストメール送信` を成功させる。
2. 差分検知テストの `Gmail検知送信も確認` を ON にして開始する。
3. 結果カードの「Gmail 検知送信」が成功し、受信箱に今回の検知メールが到着して本文に対象サイト・URL があることを確認する。

Gmail OFF の場合、認証や Gmail API は呼ばれず、カードには「実行しない」と表示される。
