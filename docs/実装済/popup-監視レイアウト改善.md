# popup監視レイアウト改善

## 目的

単一URL監視と複数URL監視の主操作を、その設定・一覧の手前に配置し、複数URL監視の状態サマリーをコンパクトにする。

## 起点

2026-09-23のユーザー依頼。単一URLの開始・停止・即座取得を「監視対象」の上へ、複数URLの全体制御を「EC監視サイト」の上へ移す。状態サマリーは横一列・コンパクト表示を希望。

## 方針

requirements・design・tasksの承認後、popupの構造とスタイルを局所的に変更する。既存の要素IDとイベント処理は維持し、入力欄のblur保存と開始クリックが競合する場合は保存完了後に開始するよう直列化する。また、単一・複数URLの実行状態を分離し、複数URL実行中でも単一URL開始を不当に無効化しない。即座取得は監視を開始しない一回限りの証跡保存として説明し、監視対象が指定URLなら一時タブでスクリーンショットとDOMのouterHTMLを取得後、元のタブへ戻して一時タブを閉じる。
