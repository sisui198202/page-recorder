# requirements.md

## 目的

PageRecorder popupで、「監視するURL」と「ECサイトの補完・診断設定」を混同せずに操作できるようにする。

## 背景

現行UIでは、複数URL監視のURLごとの監視実体と、追加時の自動入力用サイト選択が近接し、単一URL監視ではECサイトの選択トグルが監視の有効・無効に見える。

## 機能要件

1. 複数URL監視では、URLごとの監視実体と追加時のECサイト自動入力を別の役割として表示する。
2. 単一URL監視では、今回監視するページと補完・一括診断用ECサイト選択を別の役割として表示し、サイト選択はA: キーワード監視（単一URL）内のプルダウンに置く。
3. ECサイト選択を補完・一括診断用の単一選択に限定し、1件選択時には監視条件を即時反映する。
4. 表示整理によって既存の保存形式、監視開始停止、一括診断の対象決定を変えない。

## 受け入れ条件

- [x] 画面上でURL監視とECサイト選択の役割・影響範囲が分かる（自動テストでHTML構造・文言を確認）。
- [x] ECサイトをA: キーワード監視（単一URL）内のプルダウンで1件選択・解除できる（自動テストでHTML構造を確認）。
- [x] 別サイトの選択で選択先が切り替わり、過去の複数選択は解除される（単体テスト済み）。
- [x] 自動補完、一括診断、設定復元、開始停止が従来どおり動く（2026-10-11 Chrome手動確認済み）。

## スコープ外

- ECサイト選択をURL監視の有効・無効へ変更すること。
- 監視対象データへのECサイトID追加、background処理、保存スキーマの変更。
