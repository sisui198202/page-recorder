# design.md

## 概要

popupの文言・補足・アクセシビリティラベルを変更し、単一URL監視のECサイト選択状態を可視化する。既存の保存キーとイベント処理を使い続ける。

## 設計方針

- 複数URL監視は「監視対象」を「監視するURL」、「追加時に使うサイト」を「追加時のECサイト（自動入力用）」へ変更する。補足文で、既存URL・実行中監視・全体操作に影響しないことを示す。
- 単一URL監視は「監視対象」を「今回監視するページ」、「EC監視サイト」を「ECサイトの補完・診断設定」へ変更する。補足文で、選択が1件なら条件を即時反映し、未選択・複数選択なら条件を空欄にする既存動作を示す。
- ECサイトトグルのARIAラベルを補完・診断の選択操作へ変更する。通常カードには状態文言を置かず、選択済みカードだけをチェック・淡い緑の背景・枠線で強調する。
- ECサイトは単一選択とする。別サイトを選ぶと1操作で選択先を切り替え、選択済みサイトを押すと解除する。過去の複数選択はpopup表示時にすべて解除して保存する。
- 上部の`aria-live`要約は0件では選択方法、1件では選択サイトと用途を示す。

## 要件対応

| 要件 | 対応方法 |
| --- | --- |
| 1 | 複数URL監視の見出し・ラベル・補足を更新する。 |
| 2 | 単一URL監視の見出し・補足を更新する。 |
| 3 | 単一選択、選択要約、選択済みカードの視覚強調、ARIAラベルを追加し、既存の`checkAutoFill()`を維持する。 |
| 4 | `ecSiteEnabled`、`multipleSelectedEcSiteId`、background処理を変更しない。 |

## 変更対象

- `src/ui/popup.html`: 見出し・補足・状態ラベル用スタイル。
- `src/ui/popup.js`: ECサイト状態表示とARIAラベルの同期。

## テスト方針

- UIに表示する文言とトグル状態の同期を単体テストで確認する。
- Chromeで自動補完、一括診断可否、監視開始停止、選択状態復元を手動確認する。
