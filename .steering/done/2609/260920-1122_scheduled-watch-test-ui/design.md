# 設計

## 方針

- `scheduledWatchTestPanel` を、共通説明、B商品取得カード、共有Cサイト選択、C商品取得カード、C差分検知カード、結果カードの順に再編する。
- B/C商品取得カードには「変化検知なし・Gmail送信なし」を常時表示する。C差分検知カードには、一時baselineで1件を新規URLとして扱う疑似差分確認であることと、Gmail確認ON時だけ送信することを表示する。
- 既存のDOM ID、メッセージ、background API、storageキーを維持し、HTML/CSSと説明文だけを変更する。
- 結果カードの安全境界も、商品取得テストでは変化検知・Gmail送信なし、差分検知テストではGmail確認ON時のみ送信と明示する。

## 非対象

- B/Cの監視・通知・baseline・Gmail送信ロジック変更。
- C差分検知テストの擬似差分生成方式変更。
