# design — test-code-guidance

## 設計方針

- `src/ui/popup.js` の各シナリオ定義に、確認コード用の説明と再現コード用の説明を持たせる。
- 描画時はコードと説明が両方ある場合だけセクションを表示する。
- 確認コードの説明は共通定数を各表示シナリオへ設定し、再現コードの説明はシナリオ固有とする。
- HTML は説明表示用の領域だけを追加し、不要コード用の代替文言・実行タイミング固定文言は置かない。
- コピー用ボタンは HTML 初期表示と `renderCodeBlock` の描画時の両方で `コピー` とする。コピー完了・失敗メッセージには既存のコード種別ラベルを使い続ける。

## 非対象

- コード本文、コピー処理、監視設定、background I/O、検知待機の変更
- 新しいシナリオの追加
