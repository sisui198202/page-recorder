# 取得方式診断テストタブ移設計画

## 背景

取得方式診断は日常の監視開始・設定変更ではなく、Fetch HTML、表示後DOM、在庫API候補を比較する調査機能である。単一URL監視に置くと、監視対象・セレクタ・キーワードの通常設定と調査入力が結び付き、日常操作の導線も重くなる。

## 方針

- テストタブへ「取得方式診断」を追加し、一括診断、単件診断、DevTools API調査メモを集約する。
- 単件診断はアクティブタブ／指定URL、観測状態、セレクタ、キーワードを専用入力として持つ。通常監視の設定を参照・更新しない。
- 一括診断の専用ECサイト選択、診断結果の復元、Service Workerの判定・保存処理は維持する。

## 完了条件

- 通常の単一URL監視画面に診断UIが残らない。
- テストタブで一括・単件・API調査メモの全導線が利用できる。
- 診断実行後も通常監視の対象、条件、開始状態を変更しない。
