# requirements — simplify-test-scenario-labels

## 目的

A: single のテストシナリオ選択肢から不要な「【自動判定対応】」表示を削除し、読みやすくする。

## 背景

全7シナリオが自動判定対応となったため、各選択肢の重複したバッジ表記は不要になった。

## 要件

- `popup.html` の初期表示と `popup.js` によるモード切替後の選択肢で、single の全7シナリオ名を同じ簡潔な文言にする。
- 選択肢ラベルから「【自動判定対応】」を削除する。
- `supportsAutoJudgement`、シナリオ ID、自動判定の実行・結果表示は変更しない。
- 契約テストは、全7シナリオが自動判定対応であること、および選択肢ラベルにバッジがないことを検証する。

## スコープ外

- シナリオ詳細プレビュー、自動判定ロジック、シナリオ ID、監視動作の変更。

## 起点

- ユーザー提示の「テストシナリオ選択表示の簡略化」実装計画。
- `plan/todo.md` のテストシナリオ選択表示の簡略化項目。
