# イオン在庫監視セレクター更新計画

## 目的

イオンスタイルオンラインの在庫あり・在庫なし状態で共通して残る商品本体内の監視領域を採用し、PageRecorderの一括Fetch診断と監視条件の既定値を正しい状態判定へ更新する。

## 背景

既存のカート追加ボタンは在庫なし状態で存在しないため、同一セレクターを両状態で比較する一括診断では`NEEDS_REVIEW`になる。2026-09-24の診断成果物では、`#ctl00_ContentPlaceHolder1_upUpdatePanel .product__cart`が在庫あり2件・在庫なし1件のFetch HTMLとDOMに各1件あり、`カートに入れる`は在庫ありだけに存在した。

## 方針

- 状態別の実HTMLを選定根拠とし、共有ECサイト正本・Targetの構造定義・PageRecorder配布コピーを同期する。
- 購入操作用の既存`cartButton`と`inStock`は置き換えず、PageRecorderの診断既定値は専用の`pageRecorderMonitor`で分離する。
- Fetch単独監視への切替は対象外とする。
