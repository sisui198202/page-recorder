# C 差分検知の自動テスト案

## 背景

テストタブの C 安全テストは、選択サイトの商品取得と snapshot 取得だけを確認し、baseline と `newUrls` の差分検知までは確認しない。

## 提案

テスト専用セッション内で、取得した商品 URL 一覧から 1 件を除いた一時 baseline を作り、同じページの再取得で `newUrls` を意図的に発生させる。URL 取得、baseline 作成、差分検知、停止を結果カードで自動判定する。

本番の baseline、通常監視、通知、ダウンロード、設定ファイルには影響させない。Gmail 実送信の扱いは要件で決定する。
