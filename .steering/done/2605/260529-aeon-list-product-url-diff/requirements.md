# requirements — AEON 一覧 商品URL収集・差分通知

## 背景

AEON 検索結果（`ProductList.aspx`）の商品リンクは `/product/0/P-...` 形式であるが、定時差分は `ProductDetail.aspx` セレクタのため `detectedUrls` が空になり、増加検知時に一覧 URL のみが連携されていた。

## 目的

増加検知時に **新規に載った商品ページ URL だけ** を PageRecorder / 他拡張へ渡し、discord の AEON URL トリガーでカートイン〜購入フローにつなげる。

## 機能要件

1. AEON 一覧では商品1件あたり代表 URL（`.product__item--name a`）を収集する
2. 旧形式 `ProductDetail.aspx` リンクがあるページでは従来セレクタへフォールバックする
3. 前回スナップショットの URL 集合と比較し、**増えた URL のみ**を最大5件まで通知・オープン対象とする
4. 件数増加かつ新規 URL が0件のときは、一覧 URL や既存商品 URL を開かない（誤オープン防止）
5. 初回基準保存（前回スナップショットなし）では URL オープン・他拡張通知を行わない（既存どおり）

## 非機能要件

- 件数判定（`対象アイテム：N件`）は従来どおり維持
- URL は正規化（クエリ除去・末尾スラッシュ除去）して差分比較する

## 受け入れ条件

- 一覧で `ProductDetail.aspx` セレクタが 0 件、`/product/0/P-` 代表リンクが商品数と一致すること（手動コンソールと同等）
- 2回目実行で1件増えたとき、`detectedUrls` / 通知 `urls` に **増えた商品 URL のみ** が含まれる
- 新規 URL がない増加検知では商品タブを開かない

## スコープ外

- discord 側 aeon-handler の変更
- 複数同時追加時の優先順位ロジック（DOM 順の先頭から最大5件）
