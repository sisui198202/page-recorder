# 複数URL監視の情報設計改善

## 目的

複数URL監視を「確認して一括開始する」日常運用の主画面として整理する。

## 方針

- 上部に運用サマリーと全体開始・停止を集約する。
- 監視対象リストを主画面とし、状態順のコンパクト表示にする。
- 共通設定、Excel入出力、C: 複数サイト定期運用は詳細領域へ退避する。
- 既存の保存形式、アラーム、監視ロジックは変更しない。

## 現在の状況

- UI・一覧監視の実装と自動テストは完了している。
- Aの2 URL同時検知における停止完了ログの確認は、文言だけでINFOログを抑止する既存仕様により判定不能である。
- 終端ログを保全するログ重複抑止の分類定義タスクを先行し、その完了後に手動確認と完了処理を再開する。
