# ログ重複抑止の分類定義

## 目的

監視結果を示す終端ログを欠落させず、周期的な進捗ログだけを適切に抑止して、Service Workerログの追跡可能性と可読性を両立する。

## 背景

現行のbackgroundログは、INFO / DEBUGをメッセージ文字列だけで5秒間抑止する。そのため、異なるsessionIdの同じ終端ログも重複と判断され、複数URL同時検知時に2件目の停止完了ログが表示されない。

## 方針

- 終端・結果、操作・設定、周期進捗、調査詳細の4分類を定義する。
- 終端・結果ログは抑止しない。
- 周期進捗・調査詳細は、イベント種別と対象コンテキストを含むキーで短時間抑止する。
- 分類基準、対象イベント、テスト観点をログ表記ガイドへ残す。
