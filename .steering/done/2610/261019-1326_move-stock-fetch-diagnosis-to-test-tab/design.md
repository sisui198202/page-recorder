# 設計: 取得方式診断をテストタブへ移設

- テストサブタブに `diagnosis` を追加し、既存の受け入れ確認、single、multiple、B/C定時監視と排他的に表示する。
- 診断パネルは一括診断と単件診断を持つ。単件診断は対象方式、指定URL、観測状態、セレクタ、キーワードを専用要素として持つ。
- ECサイト選択は一括診断の実行対象として保持し、単件診断では選択時に既定セレクタ・キーワードを専用入力へ反映する。直接入力は可能とする。
- `diagnoseStockFetch`、`bulkDiagnoseStockFetch`、診断結果のstorageキー、ダウンロード成果物とService Workerの処理は変更しない。
- 専用の単件入力は監視設定として保存しない。サイト選択と直近診断結果は既存どおり復元する。
