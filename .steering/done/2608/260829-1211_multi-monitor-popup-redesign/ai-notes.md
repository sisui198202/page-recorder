# ai-notes

## 追加した知見

- 2026-08-29 時点の popup 運用では、主作業は `複数URL監視` 側の一覧確認、開始停止、状態把握に集約されている
- `単一URL監視` は通常運用の主導線ではなく、個別確認や EC 向け補助設定の導線として扱うと既存構成を壊さず整理しやすい
- 一覧の常時表示項目は `名前 / 状態 / URL / 開始 / 停止 / 編集 / 削除` に絞り、`キーワード / セレクタ` は編集導線へ寄せると主作業の視認性を落としにくい

## 不採用と理由

- `単一URL監視` から `複数URL監視` へ移動する専用ボタン追加は不採用
  - 既存タブ構成の軽量整理で目的を満たせるため
- `複数URL監視` の全面レイアウト再編や新規タブ追加は不採用
  - 今回は主導線の明確化と既存導線整理に範囲を限定しているため
- `監視対象リスト` への `キーワード / セレクタ` 常時表示維持は不採用
  - 主画面の情報密度が上がり、一覧確認と開始停止の主作業最短に反するため
