# 却下した改善案

計画文書の棚卸し時点で、実行候補から外した案と完了確認を記録する。却下項目は、明確な新しい利用要件または障害根拠が出るまで再起票しない。

## 却下

### 系統B/Cの統合

系統Bと系統Cは運用、保存形式、アラーム、設定入力が異なる。内部共有化の便益より既存運用への回帰リスクが大きいため、統合は実施しない。

### Content Scriptの廃止

系統Aのキーワード監視は Content Script による DOM 状態取得を必要とする。系統Aを維持する方針のため、廃止は実施しない。

### `tests/memo.md` の棚卸しを実装タスク化する案

`tests/memo.md` を確認し、認証情報および webhook は存在しなかった。現時点で実装タスクとして扱う価値がないため却下する。

### テストUIの追加改善

連続実行、プリセット URL 拡張、セレクタ事前検証、履歴保存は、現在の利用課題または優先根拠がないため却下する。

### `feature/targetpage-profiles` の旧実装をマージする案

未マージの旧ブランチは共有 targetpage の設定JSONと選択UIの一部だけを持つ。後続の個別商品 targetpage 共有・自動カート連携タスクで、同じURL・通知先を含む現行設定、通知、AutoCartAgent 連携、実機E2Eが main へ反映済みであるため、旧ブランチは統合せず削除する。旧計画にだけ残った shared からの同期は、必要になった時点で新規タスクとして起票する。

## 完了確認

### 結果自動判定

テストタブでは全7シナリオの期待結果表示に対応済みである。追加タスクにはしない。

### `startMonitoring` handler抽出

background の `startMonitoring` 処理は `startSingleMonitoring()` として抽出済みである。追加タスクにはしない。
