# requirements — multiple-test-config-foundation

## 目的

`multiple` テストシナリオの一時状態を本番の複数監視設定から分離し、設定 I/O の読込・保存・復元で既存設定を失わないようにする。

## 背景

既存の混在差分には、`multiple_test_scenario_state`、本番設定の保持、旧形式との互換読込、設定整合性修復、複数監視向けテスト基盤が同居している。これらは popup 表示や個別シナリオの変更ではなく、共通の設定境界に関する変更である。

## 受け入れ条件

- テスト用 2 件と本番 `multiple_configs` / `multiple_common_settings` を分離して保持できる。
- 読込・保存・状態取得のいずれでも、欠損値や旧形式によって本番設定が失われない。
- 設定整合性修復は対象配列を誤らず更新する。
- 新規単体テストと既存回帰テストで設定 I/O を確認する。
- `single` シナリオ3の初回検知では、取得済みの監視状態を使って保存種別を解決し、保存・停止処理を中断しない。
