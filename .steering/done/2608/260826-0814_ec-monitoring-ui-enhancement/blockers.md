# 🚧 blockers.md

## 🎯 目的

タスクの進行を阻害している要因（Blocker）を明確にし、
解消アクションを管理する。

---

## 📌 使い方

- 「止まっている理由」を必ず記録する
- 放置せず、解決方法と担当を明確にする
- 解消したらステータスを更新する

---

## 🧩 Blocker一覧

（現時点ではBlockerなし）

---

## 📝 運用ルール

- Blockerは必ずID（B-XXX）で管理する
- 同時に複数あってもよい
- 小さな問題でも記録してよい
- 解消したら履歴として残す（削除しない）

---

## 🔄 更新フロー

```text
1. Blocker発生
2. blockers.md に追加
3. 対応
4. ステータス更新
```

## 🚫 アンチパターン

* ❌ 頭の中だけで管理する
* ❌ 曖昧なまま放置する
* ❌ 解消後に削除する（履歴が消える）
