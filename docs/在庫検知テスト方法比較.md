# 在庫検知テスト方法比較: ベースライン操作 vs 直接通知送信

## 概要

PageRecorder の在庫検知機能をテストする2つの方法の違いと、それぞれの用途を整理する。

---

## テスト方法の比較表

| 観点 | 方法1: ベースライン操作 | 方法2: 直接通知送信 |
|------|------------------------|-------------------|
| **処理フロー** | 完全な検知フローを通る | 検知フローをバイパス |
| **ベースライン影響** | 検知成功時に更新される | 変更されない（減らしたまま） |
| **テスト範囲** | DOM取得 → 差分検出 → 通知送信 | 通知送信のみ |
| **所要時間** | リロード間隔分の待機必要（10秒〜1分） | 即座に実行可能 |
| **ダウンロードファイル** | `detected_*.txt` が生成される | 生成されない |
| **ログ出力** | `scheduledStockLogs` に記録される | 記録されない |
| **用途** | 差分検知ロジック検証 | Discord連携のみの動作確認 |

---

## 方法1: ベースラインから1件削除 + 監視実行

### 概要

ベースライン（`scheduledStockSnapshots`）から特定のURLを削除し、
`startScheduledStockWatch()` で監視を実行する。
一覧ページをリロードした際に、削除したURLが「新規」として検知される。

### 実行コード

**Step 1: ベースラインから1件削除**

```javascript
(async function () {
  const MONITOR_KEY =
    'https://aeonretail.com/Form/Product/ProductList.aspx?gspsk=%e3%83%9d%e3%82%b1%e3%83%a2%e3%83%b3%e3%82%ab%e3%83%bc%e3%83%89%e3%82%b2%e3%83%bc%e3%83%a0&psc=0';
  const REMOVE_URL =
    'https://aeonretail.com/product/0/P-2319294424002/P-231929442400201/';

  const store = await chrome.storage.local.get('scheduledStockSnapshots');
  const snapshots = store.scheduledStockSnapshots || {};
  const snap = snapshots[MONITOR_KEY];
  if (!snap?.urls?.length) {
    console.error('baseline がありません');
    return;
  }

  const norm = function(u) { return u.replace(/\/$/, ''); };
  var nextUrls = snap.urls.filter(function(u) { return norm(u) !== norm(REMOVE_URL); });
  if (nextUrls.length === snap.urls.length) {
    console.error('REMOVE_URL が baseline にありません');
    return;
  }

  snapshots[MONITOR_KEY] = { count: snap.count, urls: nextUrls, checkedAt: snap.checkedAt };
  await chrome.storage.local.set({ scheduledStockSnapshots: snapshots });
  console.log('OK', { before: snap.urls.length, after: nextUrls.length, removed: REMOVE_URL });
})();
```

**Step 2: 監視実行**

```javascript
await self.startScheduledStockWatch()
```

### 処理フロー

```
ベースライン削除
    ↓
startScheduledStockWatch()
    ↓
一覧タブを開く / リロード
    ↓
DOM から商品URL一覧を取得
    ↓
ベースラインと比較
    ↓
新規URL検出 (newUrls)
    ↓
scheduledStockLogs に記録
    ↓
detected_*.txt をダウンロード
    ↓
外部拡張へ通知送信 (PAGE_RECORDER_STOCK_DETECTED)
    ↓
ベースラインを現在のURLリストで更新
```

### 検証できる内容

- 一覧ページのDOM取得が正常に動作するか
- 差分検出ロジックが正しく動作するか
- `scheduledStockLogs` への記録が行われるか
- `detected_*.txt` のダウンロードが成功するか
- 外部拡張への通知送信が成功するか
- ベースラインの更新が行われるか

### 結果の確認方法

```javascript
// ログ確認
chrome.storage.local.get('scheduledStockLogs').then(function(r) {
  var log = (r.scheduledStockLogs || []).slice(-1)[0];
  console.log('newUrls:', log && log.newUrls);
});
```

### 注意点

- **検知成功時**: ベースラインが現在の一覧で上書きされる（urls が元に戻る）
- リロード間隔分の待機が必要（popup設定による）
- 実行場所: **Service Worker コンソールのみ**

## 方法2: 直接通知送信

### 概要

PageRecorder の検知フローを通さず、直接 `chrome.runtime.sendMessage()` で
外部拡張（discord_post_url_monitor）に通知を送信する。

### 実行コード

```javascript
chrome.runtime.sendMessage('ibmbjnemcpminbmenepldhockemdpomc', {
  type: 'PAGE_RECORDER_STOCK_DETECTED',
  source: 'PageRecorder',
  siteId: 'aeon',
  discordChannelId: '1512256504668094514',
  urls: ['https://aeonretail.com/product/0/P-2319294424002/P-231929442400201/'],
  targetUrl: 'https://aeonretail.com/Form/Product/ProductList.aspx?gspsk=%e3%83%9d%e3%82%b1%e3%83%a2%e3%83%b3%e3%82%ab%e3%83%bc%e3%83%89%e3%82%b2%e3%83%bc%e3%83%a0&psc=0',
  title: 'manual test aeon',
  count: 1
}).then(console.log).catch(console.error)
```

### 処理フロー

```
sendMessage() 実行
    ↓
外部拡張が受信 (onMessageExternal)
    ↓
payload 検証
    ↓
URL オープン（設定による）
    ↓
Discord 投稿（設定による）
    ↓
sendResponse で結果を返す
```

### 検証できる内容

- 外部拡張へのメッセージ送信が成功するか
- payload の形式が正しいか
- 外部拡張の受信処理が動作するか
- Discord 投稿が成功するか
- URLオープン機能が動作するか

### 結果の確認方法

```javascript
// 即座にレスポンスが返る
// 成功例: { success: true, openedCount: 1 }
// 失敗例: { success: false, error: "channel_not_found" }
```

### 注意点

- **ベースラインは変更されない**: 方法1で1件減らした状態のままになる
- `scheduledStockLogs` には記録されない
- `detected_*.txt` はダウンロードされない
- 実行場所: Service Worker コンソール または 通常ページのコンソール

---

## 使い分けの指針

### 方法1 を使うべき場面

| 場面 | 理由 |
|------|------|
| 差分検知ロジックの検証 | DOM取得→比較→検出の全フローを通るため |
| ダウンロード機能の検証 | `detected_*.txt` が生成されるため |
| ベースライン更新の検証 | 検知後にベースラインが更新されるため |
| 本番に近い E2E テスト | 実際の監視フローを再現するため |

### 方法2 を使うべき場面

| 場面 | 理由 |
|------|------|
| Discord 連携のみの検証 | 検知フローをスキップして高速にテストできる |
| 外部拡張の受信処理検証 | payload 形式や受信処理の動作確認に特化 |
| 繰り返しテスト | 即座に実行でき、待機時間がない |
| ベースラインを維持したい | ベースラインを変更せずにテストできる |

## テスト後の後処理

### 方法1 の後処理

検知成功時はベースラインが自動更新される。
検知前に中断した場合や、方法2のみ実行した場合は手動復元が必要。

**ベースラインを手動復元**

```javascript
(async function () {
  const MONITOR_KEY =
    'https://aeonretail.com/Form/Product/ProductList.aspx?gspsk=%e3%83%9d%e3%82%b1%e3%83%a2%e3%83%b3%e3%82%ab%e3%83%bc%e3%83%89%e3%82%b2%e3%83%bc%e3%83%a0&psc=0';
  const RESTORE_URL =
    'https://aeonretail.com/product/0/P-2319294424002/P-231929442400201/';

  const store = await chrome.storage.local.get('scheduledStockSnapshots');
  const snapshots = store.scheduledStockSnapshots || {};
  const snap = snapshots[MONITOR_KEY];
  if (!snap) {
    console.error('キーがありません');
    return;
  }

  const norm = function(u) { return u.replace(/\/$/, ''); };
  var urls = snap.urls || [];
  if (urls.some(function(u) { return norm(u) === norm(RESTORE_URL); })) {
    console.log('すでに baseline に含まれています', { urls: urls.length });
    return;
  }

  snapshots[MONITOR_KEY] = {
    count: snap.count,
    urls: urls.concat([RESTORE_URL]),
    checkedAt: new Date().toISOString()
  };
  await chrome.storage.local.set({ scheduledStockSnapshots: snapshots });
  console.log('復元しました', { urls: snapshots[MONITOR_KEY].urls.length });
})();
```

### 方法2 の後処理

ベースラインは変更されないため、後処理は不要。
ただし、**方法1で削除した後に方法2だけ実行した場合**は、
ベースラインが減ったままなので復元が必要。

## ベースライン状態の確認

```javascript
chrome.storage.local.get('scheduledStockSnapshots').then(function(r) {
  var snapshots = r.scheduledStockSnapshots || {};
  Object.keys(snapshots).forEach(function(url) {
    var data = snapshots[url];
    console.log(url.slice(-50), 'count:', data.count, 'urls:', (data.urls || []).length, 'at:', data.checkedAt);
  });
});
```

| `urls` の値 | 状態 |
|------------|------|
| 20 前後 | 正常（1ページ分の商品数） |
| 19 | テストで1件削除したまま → **復元が必要** |
| 0 | ベースラインなし |
