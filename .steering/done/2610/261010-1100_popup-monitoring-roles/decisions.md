# decisions.md

## D-001: ECサイト選択を補完・診断に限定する

- 決定内容: ECサイトのON/OFFを監視の有効・無効へ変更せず、補完・一括診断用の選択として表示する。
- 背景: URLごとの監視対象とECサイト選択は独立しており、現在の見出しでは誤解を招く。
- 採用理由: 保存スキーマとbackground処理を変えず、既存の自動補完・診断導線を明確にできる。
- ステータス: 確定。

## D-002: ECサイト選択を単一選択に限定する

- 決定内容: 別サイト選択時は既存選択を置換し、過去の複数選択は解除する。
- 背景: 複数選択では監視条件が空欄になり、一括診断も実行できず、有効な機能がない。
- 採用理由: 1操作で選択先を切り替えられ、補完・診断用という役割と一致する。
- ステータス: 確定。
