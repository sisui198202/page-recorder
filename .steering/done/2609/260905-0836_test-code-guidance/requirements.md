# requirements — test-code-guidance

## 目的

popup のテストシナリオで、確認コードと再現コードの役割、副作用、不要時の扱いを明確にする。

## 要件

- 上段の見出しを `ページ状態の確認コード` に変更し、DevTools Console で一致件数と対象テキストを表示し、ページ内容を変更しないことを示す。
- 下段の見出しを `検知を再現するコード` に変更する。
- 再現コードがあるシナリオでは、変更対象、実行タイミング、再読み込みで元に戻ることをシナリオ別に示す。
- 再現コードがないシナリオでは、下段セクションとコピー操作を表示しない。
- 確認コード・再現コード欄のコピー用ボタンは、ともに `コピー` と表示する。
- 監視・保存処理、コピー機能、Service Worker 側の待機・検知仕様は変更しない。

## 起点

- `plan/docs/test-code-guidance.md`
- スクリーンショットで確認したテストコード欄の曖昧さ
