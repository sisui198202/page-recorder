---

## ✅ チェック状態の定義

- 未着手: 今回タスクで対応予定の項目
- 実装済み・未確認: 実装は完了したが、確認が未完了の項目
- [x] 完了。対象項目について、実装と確認の両方が完了した項目
- [-] 保留。このタスクでは今回対応しないが、再検討・対応余地がある項目
- [/] 却下。今回タスクでは不採用確定の項目

---

## 📋 進め方ルール

- Phase 単位で進める
- 各項目は実行した直後に状態を更新する
- 各 Phase ごとに `実装` と `確認` をセットで完了させる
- 実装だけ完了した項目は「実装済み・未確認」に更新する
- 実装と確認の両方が完了した項目だけを `[x]` に更新する
- 今回未対応の論点は `[-]` または `[/]` で明示する
- `tasks.md` の状態と実際の進捗を常に一致させる
