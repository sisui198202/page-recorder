# design — multi-monitor-popup-redesign

## ステータス

更新済み。`requirements.md` の前提と 2026-08-29 の追加判断を反映した設計方針。

## 設計方針

- 最適化対象は `一覧確認 / 開始停止 / 状態把握` の主作業最短とする
- 既存タブ構成は維持し、popup の初期表示と案内文言で `複数URL監視` を主導線化する
- 主画面上部の状態把握は `件数中心サマリー` とし、表示項目は `監視中件数 / 停止中件数` とする

## 今回確定した設計判断

- `単一URL監視` タブ上部に補助導線説明を置く
- 補助導線説明の基準文言は `通常運用は複数URL監視です。ここでは個別確認や EC 向け補助設定を行います。` とする
- 補助導線説明は `監視対象` セクションより前、または直下の説明領域に置く
- `単一URL監視` から `複数URL監視` へ移動する専用ボタンやリンクは追加しない
- `監視対象リスト` の常時表示項目は `名前 / 状態 / URL / 開始 / 停止 / 編集 / 削除` に限定する
- `監視対象リスト` から `キーワード` と `セレクタ` の常時表示を外し、確認・変更は既存の `編集` 導線で行う
- `件数中心サマリー` は今回の popup に実際に追加する
- `複数URL監視` 側にも `EC監視サイト` の 1 サイト選択 UI を置く
- `複数URL監視` の `EC監視サイト` は、新規監視対象追加モーダルへ `src/config/ec-sites.json` の `セレクタ / キーワード` を自動補完するために使う
- `全体制御` の `全て開始` `全て停止` は今回も必要な中核操作として維持する
- 折りたたみ対象は `共通監視設定` `共通時間設定` `📊 設定管理` のみとする
- `監視対象リスト` と `全体制御` は常時表示とする
- 折りたたみ対象 3 セクションの初期状態はすべて `閉じる` とする
- 折りたたみ状態は保存し、popup 再表示時に復元する
- 折りたたみ UI は既存 `section` 単位の軽量追加で対応し、別モーダル化やタブ増設は行わない
- 折りたたみ UI は見出し行全体を開閉トリガーにし、右端に `開く / 閉じる` ラベルを表示する
- 閉じた状態では本文のみ `display: none` にする
- `📊 設定管理` は `全体制御` の内側ではなく独立 section にする

## 画面構成

- `複数URL監視` タブを初期表示対象とする
- タブ内の主構成は `件数中心サマリー` → `EC監視サイト` → `全体制御` → `監視対象リスト` → `共通監視設定 / 共通時間設定 / 📊 設定管理` の順とする
- `監視対象リスト` は主画面として扱い、一覧確認と個別開始停止に必要な情報を優先表示する
- `件数中心サマリー` の表示項目は `監視中件数 / 停止中件数` の 2 項目に固定する
- `単一URL監視` タブは残し、個別確認・EC補助導線であることが分かる補助説明を追加する
- `複数URL監視` の `EC監視サイト` は 1 サイト選択の dropdown とし、追加時補助に限定する

## 変更対象と非対象

- 変更対象は popup の表示構成、説明文言、折りたたみ UI、一覧表示項目の整理に限定する
- 外部 API、保存スキーマ、background I/O 境界、通知境界は変更しない
- 既存の `開始 / 停止 / 編集 / 削除` 操作導線は維持する

## 実装時の確認観点

- popup 初期表示で `複数URL監視` が主導線として見えること
- `件数中心サマリー` として `監視中件数 / 停止中件数` が表示されること
- `単一URL監視` に補助説明が表示されること
- `複数URL監視` に `EC監視サイト` の 1 サイト選択 UI が表示されること
- `新しい監視対象を追加` 時に、選択サイトの `セレクタ / キーワード` がモーダルへ自動補完されること
- `監視対象リスト` に `名前 / 状態 / URL` と 4 操作ボタンが見え、`キーワード / セレクタ` が常時表示されないこと
- `全体制御` と `監視対象リスト` が常時表示されること
- `共通監視設定` `共通時間設定` `📊 設定管理` が開閉でき、popup 再表示時に開閉状態が復元されること
- `編集` 導線から従来どおり `キーワード / セレクタ` を確認・変更できること
- `全て開始 / 全て停止 / 状態更新` と各行 `開始 / 停止 / 編集 / 削除` が回帰しないこと
