# Excel取込のファイル選択テスト

## 目的

popup の「Excel取込」から同期native file inputのファイル選択を開き、既存の取込処理へ進めることを確認する。

## 実行

1. `chrome://extensions` で PageRecorder をリロードする。
2. popup の「複数URL監視」タブを開き、「設定管理」を開く。
3. 「Excel取込」を選択する。
4. Chrome for Testing 136で、macOS のファイル選択ダイアログが表示され、`.xlsx`、`.xls`、`.csv` を選択できることを確認する。
5. 既存の有効なExcelまたはCSVを選択し、進捗表示と取込後の監視対象一覧更新を確認する。
6. もう一度「Excel取込」を選び、ファイル選択をキャンセルする。取込要求・設定変更・エラー表示が発生しないことを確認する。

## 合格条件

- ボタン選択直後にファイル選択ダイアログが開く。
- ファイル選択後に既存の取込成功・失敗メッセージが表示される。
- キャンセル時に取込メッセージや設定変更が発生しない。
