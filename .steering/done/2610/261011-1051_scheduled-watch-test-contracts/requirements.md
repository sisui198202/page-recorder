# requirements.md

## 目的

現行実装と不一致になったユニットテスト2件を整理し、仕様に沿った回帰テストへ戻す。

## 背景

全ユニットテストを再実行した結果、今回の変更範囲外の失敗が2件見つかった。既に成功している`scheduled-watch-ui-contract`は対象外とする。

- `scheduled-watch-diff-test`: 保存付き差分テストが、baseline後に短縮経路で検知・終了まで完了する現行実装に対し、中間の`phase: detect`がstorageに残ることを期待している。
- `stock-fetch-diagnosis`: popupが定時監視設定も並行読込するようになったが、単体テストが新しいローダー依存を注入していない。

## 受け入れ条件

- [x] 現行の保存付き差分テストの短縮挙動を維持し、最終結果・成果物・session後始末を検証する単体テストに更新する。
- [x] 在庫取得診断の単体テストで、定時監視設定ローダー依存を注入し、フォーム値優先・ECサイト設定フォールバックを検証する。
- [x] `npm run test:unit -- --runInBand` が成功する。
- [x] 対象2テストと全ユニットテストで既存挙動に回帰がないことを確認する。

## スコープ外

- popup監視対象・ECサイト役割整理のUI変更。
- 短縮検証／実運用再現を選ぶテストタブUIの追加（P2の別タスク）。
- 定時監視機能の新規追加や仕様拡張。
