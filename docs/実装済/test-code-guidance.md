# テストコード欄の役割明確化

## 背景

popup のテストシナリオでは、ページ状態の確認用コードと検知を再現するコードが同じように見え、ページ変更の有無や実行要否を判断しにくかった。

## 方針

- 上段を `ページ状態の確認コード` とし、非破壊であることを明示する。
- 下段を `検知を再現するコード` とし、コードがあるシナリオでは変更対象・実行タイミング・再読み込みで元に戻ることを表示する。
- 再現コードがないシナリオでは、下段のコード枠とコピー操作を表示しない。
- 監視・保存処理、コピー機能、Service Worker 側の待機・検知仕様は変更しない。
