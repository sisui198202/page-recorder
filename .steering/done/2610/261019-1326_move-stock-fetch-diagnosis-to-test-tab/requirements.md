# 要件: 取得方式診断をテストタブへ移設

## 目的

Fetch / DOM / API調査を、通常監視と独立したテストタブの調査機能として提供する。

## 受け入れ条件

- テストタブに「取得方式診断」サブタブがあり、一括診断、単件診断、API調査メモを実行できる。
- 単一URL監視から診断UIを削除する。
- 単件診断は専用の対象・条件入力で実行し、通常監視設定を変更しない。
- 一括診断のサイト選択・実行可否・結果復元、単件診断の結果復元、保存成果物を維持する。
- 関連する自動テストと構文検査が成功する。

## 起点

- リポジトリ: `PageRecorder`
- 計画: `plan/docs/取得方式診断テストタブ移設計画.md`
- 対象: `src/ui/popup.html`、`src/ui/popup.js`、`tests/unit/stock-fetch-diagnosis.test.js`、関連手動確認書とPRD
