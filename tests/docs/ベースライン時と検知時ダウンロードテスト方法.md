## 最短手順

1. Alfred で `tes'` を開き、`テスト用:設定バックアップ` を実行
2. 対象サイトの `絞り込み` を実行して、今回確認するサイトだけを `enabled=true` にする
3. 対象サイトの `時間設定(baselineTime + schedules)` を実行
4. `chrome://extensions` で PageRecorder と受信側拡張をリロードする
5. PageRecorder の Service Worker Console と受信側拡張の Console を開く
6. 以降の確認は [定時差分検知 — newUrls 検証手順](./docs/scheduled-stock-diff-detection-verification.md) を使う
